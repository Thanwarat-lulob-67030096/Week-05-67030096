คำถามเพิ่มเติม:

เปรียบเทียบประสบการณ์การใช้ Docker ในสัปดาห์นี้กับสัปดาห์ที่ 4: สัปดาห์นี้การใช้ Docker รู้สึกคล่องตัวและเข้าใจมากขึ้น สามารถจัดการ container และ environment ได้เองโดยไม่ต้องพึ่งคำสั่งตัวอย่างเหมือนครั้งก่อน การ build และ run โค้ดผ่าน ESP-IDF ภายใน Docker ทำได้รวดเร็วและไม่พบปัญหาการตั้งค่าเหมือนสัปดาห์ที่ 4
สิ่งที่เรียนรู้เพิ่มเติมเกี่ยวกับ ESP32 architecture: ได้เข้าใจโครงสร้างการทำงานของ ESP32 ในระดับลึก ทั้งระบบหน่วยความจำ การทำงานของ cache และการแบ่งหน้าที่ของแต่ละ core โดยเฉพาะการทำงานแบบ dual-core ที่ช่วยให้โปรแกรมทำงานพร้อมกันได้อย่างมีประสิทธิภาพ
ความท้าทายที่พบในการทำ architecture analysis: ความท้าทายคือการทำความเข้าใจการเชื่อมโยงระหว่างหน่วยความจำ (SRAM, Flash, Heap, Stack) และการวิเคราะห์ผลการทำงานของ cache ซึ่งต้องอาศัยการสังเกตค่าที่เปลี่ยนแปลงเล็กน้อย นอกจากนี้การตั้งค่าให้ทั้งสอง core ทำงานพร้อมกันโดยไม่ชนกันก็ต้องเข้าใจระบบ queue และ scheduling ของ FreeRTOS อย่างละเอียด
